# DNDT/DNDF Track A Evidence

This folder contains the compact outputs from the completed DNDF paper-protocol
audit. The authenticated design comprises ten folds for each of three modes:
released author behaviour, fresh-fold author protocol, and corrected reference
evaluation. The manifest records 30 completed units out of 30 required units.

The complete non-checkpoint run is stored in:

`artifacts/bundles/dndt_dndf_track_a_evidence_20260826.tar.gz`

SHA-256:

`54b70b902f69e732c35691d0b46a8ab023a5b0735c303011d1addba28ecf82e3`

The archive contains fold-level predictions, metrics, authenticated receipts,
run contracts, RFECV exposure records, and checkpoint manifests. PyTorch `.pt`
checkpoint and recovery binaries are excluded because they are regenerable from
the committed implementation and recorded configuration. Their manifests and
hashes remain in the archive for provenance.

Track A estimates paper-protocol behaviour and the effect of controlled protocol
corrections. It must not be presented as the strict COVID-RARS deployment result;
that role belongs to Track B.
